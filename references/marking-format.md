# Question and marking format

Use this pattern for each requested question. Replace placeholders; do not emit them.

Question [label]

[Student-facing question.] [single target code]

Related rubric

[Area B1 or B2] — [code]: [verified wording, or labelled accurate paraphrase].

[If necessary, state the component of a broader descriptor being assessed.]

Suggested marking scheme — proposed wording

| Basic performance | Good performance | Excellent performance |
|---|---|---|
| [Observable Basic evidence and example, or explain that the response provides only partial evidence below a named official descriptor.] | [Observable Good evidence and example, or Not targeted by this question.] | [Observable Excellent evidence and example, or Not targeted by this question.] |

[Brief acceptance notes and limitations.]

Record the demonstrated performance as evidence towards the overall [B1/B2] judgement out of 10.

## Evidence rules

- Use one target descriptor, with subordinate performance evidence in the table. Do not append multiple codes to the question merely because lower performance is recognised.
- Make every condition needed for the target visible in the prompt. Do not award excellence for a conclusion that did not ask for generalisability, a hypothesis without evidential reasoning, or explanation of simple data merely because it contains detailed biology.
- Do not manufacture a Basic descriptor for an official rubric row with no Basic entry. You may describe partial evidence in the Basic column, explicitly noting that it does not by itself demonstrate a separate official Basic descriptor. Similarly, do not call an incorrect or vague response Basic unless it supplies valid Basic evidence.
- Examples illustrate acceptable evidence, not a compulsory answer. Label all invented numbers as hypothetical. Do not reproduce teacher answer examples on the student task sheet during final assembly.
- If two procedures or variables are required, recognise partial evidence from one adequate response without inventing an all-or-nothing scoring formula.
- More words, equipment or jargon do not in themselves demonstrate a higher level.
